# PartSnap MVP v0.10

Главное изменение — исправлен слишком широкий поиск eBay.

Теперь:
- AI возвращает `part_class` и `search_query_en`;
- eBay запрос идёт в категорию Autoteile & Zubehör (6030), а не по всему eBay;
- в запрос передаются Year / Make / Model / Engine через compatibility_filter, когда данных достаточно;
- результаты фильтруются по смыслу названия: например, для battery дворники и фильтры получают сильный штраф и отбрасываются;
- сначала предпочитаются EXACT/POSSIBLE compatibility, потом релевантность, потом итоговая цена;
- в выдаче показываются фото и название конкретного eBay-товара;
- совместимость eBay показывается отдельным бейджем, если API её вернул.

Важно:
eBay compatibility зависит от категории и от того, заполнил ли продавец fitment-данные.
Поэтому отсутствие EXACT не означает несовместимость — PartSnap всё равно сохраняет предупреждение, пока не подключён полноценный внешний fitment-каталог.
