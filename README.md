# PartSnap MVP v0.10.3

Исправления после первого живого поиска Bosch S4:

- для пользователей из ЕС eBay сначала ищется по продавцам из ЕС;
- глобальные/US предложения остаются только как последний fallback;
- в eBay contextualLocation теперь передаётся почтовый индекс, если он указан;
- модельные токены вроде `S4` стали обязательными для результата:
  если пользователь ищет Bosch S4, Bosch S6588b больше не пройдёт фильтр;
- EU-продавцы ранжируются выше non-EU;
- в интерфейсе показывается бейдж `ЕС` / `вне ЕС`;
- если индекс не введён, PartSnap предупреждает, что доставка может быть неточной.

Цель: адекватные цены для реального пользователя, а не американские товары с доставкой €300.
