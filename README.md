# PartSnap MVP v0.9.1

Hotfix для первого живого теста eBay.

- Поиск товаров больше не блокируется без подтвержденного fitment.
- Неподтвержденные результаты показываются с явным предупреждением.
- Интерфейс сообщает, если eBay подключен, но результатов нет.
- Интерфейс сообщает, если eBay API вернул ошибку.
- Подтвержденная совместимость останется отдельным статусом, когда подключим внешний каталог.
