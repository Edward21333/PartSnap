# PartSnap MVP v0.6

## Что изменилось
- проект подготовлен к публичному Docker/Render-деплою;
- добавлен первый **реальный merchant adapter: eBay Browse API**;
- eBay включается автоматически после добавления `EBAY_CLIENT_ID` и `EBAY_CLIENT_SECRET`;
- если eBay недоступен, приложение не падает и продолжает demo-выдачу;
- география, доставка и сортировка по полной цене сохранены;
- архитектура готова для TecDoc Web Service.

## Почему eBay первым
У Browse API есть официальный поиск товаров, данные цены/доставки и автомобильная compatibility-функциональность. Это позволяет проверить живой сценарий PartSnap до переговоров с десятками магазинов.

## Что нужно от владельца проекта
Для реального запуска понадобятся аккаунты/ключи:
1. OpenAI API — распознавание фото.
2. eBay Developers — первый live источник товаров.
3. Позже TecAlliance/TecDoc — каталог/OEM/VIN.

См. `DEPLOY_RENDER.md`.
