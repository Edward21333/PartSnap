# PartSnap MVP v0.12

Главное изменение: рейтинг совместимости по характеристикам.

Для аккумуляторов:
- PartSnap сравнивает Voltage / Ah / CCA исходной детали и eBay-товара;
- каждому товару присваивается score 0–100%;
- сильные несовпадения отбрасываются;
- сортировка теперь: ЕС → лучший fit score → eBay compatibility → релевантность → итоговая цена;
- товары без указанных характеристик не удаляются, но идут ниже товаров с подтверждаемыми specs;
- в каждой карточке видно `Совпадение характеристик XX%`.

Важно:
это технический compatibility score, а не официальный fitment автомобиля.
До подключения TecDoc/Ovoko/VIN-каталога PartSnap продолжает честно показывать общее предупреждение.
