# PartSnap MVP v0.14

Новая логика доверия к автомобилю.

Если автомобиль НЕ подтверждён:
- марка/модель/год/двигатель — только мягкая подсказка;
- eBay compatibility_filter не используется;
- объявления для других машин не называются «вероятно подходят»;
- вместо этого PartSnap пишет `Та же деталь · авто не подтверждено`;
- поиск опирается прежде всего на фото, маркировку и тип детали.

Если автомобиль подтверждён:
- пользователь включает `Автомобиль точно известен`, либо успешный VIN decode включает это автоматически;
- другая явно указанная машина становится сильным mismatch;
- eBay compatibility_filter включается.

PartSnap должен работать и с деталями неизвестного происхождения.
