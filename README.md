# PartSnap MVP v0.18

Исправлен корень проблемы с `GO 295`.

Почему появлялись цепи/шины:
раньше fallback мог искать eBay по голой маркировке `GO 295`.
eBay воспринимал `295` как размер шин и возвращал snow chains / Schneeketten.

Что изменено:
- для CV joint маркировка никогда не ищется сама по себе;
- варианты теперь: `GO 295 CV joint`, `GO 295 Gelenksatz`, `GO295 CV joint`, затем семантические fallback-запросы;
- добавлен фильтр шума для snow chains / tyre / tire / Reifen / 295/30 и т.п.;
- если в заголовке есть такие слова, но нет признаков CV joint / Gelenksatz / Gleichlaufgelenk / driveshaft, результат выбрасывается;
- в диагностике сохраняется список query variants.

Цель:
сохранить широкую eBay-выдачу, но не позволять цифровой маркировке уводить поиск в случайную товарную категорию.
