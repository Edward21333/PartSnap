# PartSnap MVP v0.12.2

Mobile upload hotfix.

Причина бага:
`<input type="file" accept="image/*" capture="environment">`
на телефонах принудительно открывал камеру.

Исправлено:
- «Выбрать из галереи» — обычный image file input без `capture`;
- «Сфотографировать» — отдельный input с `capture="environment"`;
- оба варианта используют один и тот же preview и дальнейший AI-анализ;
- на узком экране кнопки автоматически становятся одна под другой.

Функциональность v0.12.1 сохранена.
