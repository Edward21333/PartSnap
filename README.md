# PartSnap MVP v0.8

Главная идея версии: не показывать «точно подходящую» деталь, если совместимость не подтверждена.

Что добавлено:
- поле ручного OEM/артикула;
- AI пытается отдельно считать реальную маркировку с фотографии;
- backend различает:
  1. ручной номер,
  2. маркировку с фото,
  3. AI-подсказку,
  4. отсутствие номера;
- новый endpoint `/api/part/resolve`;
- блок совместимости честно показывает, подтверждена она или нет;
- поиск цен не запускается без хоть какого-то артикула/идентификатора;
- архитектура готова для будущей проверки через TecDoc/Ovoko/VIN.
