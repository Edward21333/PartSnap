# PartSnap MVP v0.11.1

Hotfix.

Причина падения v0.11:
в Python f-string внутри AI prompt был добавлен JSON-блок `specs` с одинарными `{}`.
Python воспринял его как форматирование строки и выбросил:
`ValueError: Invalid format specifier`.

Исправлено:
- фигурные скобки `specs` экранированы как `{{ }}`;
- frontend теперь не пытается слепо парсить любой 500-ответ как JSON;
- при серверной ошибке пользователь увидит нормальное сообщение вместо `Unexpected token ...`.

Функциональность v0.11 (Voltage/Ah/CCA) сохранена.
