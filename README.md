# PartSnap MVP v0.16

Классификатор eBay-результатов стал строже по сущности товара.

Теперь группы:
1. Сама деталь
2. Возможные аналоги
3. Похожие / смежные детали
4. Сопутствующие товары
5. Остальные результаты eBay

Для CV joint:
- CV joint / Gelenksatz / Außengelenk -> сама деталь
- driveshaft / Antriebswelle -> похожая / смежная сборка
- boot / gaiter / manschette / grease / clamp / strap / repair kit -> сопутствующий товар
- wheel bearing / ABS sensor -> другой товар

Важно:
если автомобиль не подтверждён, PartSnap пишет
`Сама деталь · применимость не проверена`,
а не создаёт впечатление, что деталь точно подходит к введённой машине.

Лучшая цена считается только по самой детали / возможным аналогам.
