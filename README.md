# PartSnap MVP v0.9

Главные изменения:
- при первом открытии больше НЕТ старого фото Golf и заранее заполненного Volkswagen 1.6;
- стартовый экран чистый: пользователь сам добавляет фото и автомобиль;
- добавлена кнопка «Заполнить авто по VIN»;
- VIN helper использует публичный NHTSA vPIC только для базовой идентификации автомобиля;
- vPIC НЕ считается каталогом запчастей и не подтверждает fitment;
- добавлена архитектура FitmentResolver для будущего TecDoc/Ovoko;
- поиск цен блокируется, пока внешний каталог не подтвердит совместимость;
- принцип v0.9: лучше показать 0 товаров, чем неподходящую запчасть.

Важно:
пока TecDoc/Ovoko API не подключены, fitmentVerified останется false.
Это ожидаемое поведение, а не ошибка.
