# PartSnap MVP v0.20

Выбор автомобиля переработан.

- свободного ввода марка/модель/год/двигатель больше нет;
- режим `Автомобиль неизвестен`;
- режим `Выбрать из каталога` с зависимыми списками марка → модель → год → двигатель;
- успешный VIN decode переводит состояние в `подтверждён по VIN`;
- только VIN-состояние отправляет vehicle_verified=true;
- каталог вынесен в app/vehicle_catalog.json и позже может быть заменён внешним API без переделки UI.

Текущий vehicle_catalog.json — стартовый MVP-набор, не полный мировой парк автомобилей.
