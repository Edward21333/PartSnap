# PartSnap MVP v0.19

Главное изменение — уровни достоверности результата.

Теперь PartSnap различает:
- Точное совпадение по eBay — только если eBay вернул EXACT compatibility;
- Тот же тип детали — например, это действительно наружный ШРУС, но применимость не проверена;
- Возможный аналог;
- Похожая / смежная деталь;
- Сопутствующий товар;
- Остальной результат.

Важно:
раньше надпись `Сама деталь` могла звучать так, будто PartSnap доказал, что это именно нужный ШРУС.
Теперь формулировки честнее и не создают ложной уверенности.
