# PartSnap MVP v0.11

Главный шаг: теперь PartSnap сравнивает характеристики детали, а не только название.

Для аккумуляторов:
- AI пытается считать с фото Voltage / Ah / CCA;
- значения показываются пользователю и могут быть исправлены вручную;
- eBay-объявления разбираются по названию;
- явные несоответствия по Voltage/Ah/CCA отбрасываются;
- совпадающие характеристики получают приоритет;
- в карточке товара видно, какие specs удалось извлечь;
- это НЕ заменяет официальный fitment-каталог и не называется «подтверждённой совместимостью».

Почему это полезно:
Bosch S4 — линейка разных аккумуляторов. Теперь дешёвый S4 на 52Ah не должен автоматически считаться хорошим вариантом, если на исходном аккумуляторе указано, например, 70Ah.

Следующий настоящий уровень — официальный каталог/VIN resolver (TecDoc/Ovoko или другой лицензированный источник).
