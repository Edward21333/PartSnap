# PartSnap MVP v0.10.1

Исправление поиска eBay после v0.10.

Теперь поиск идёт каскадом:
1. точная категория детали + compatibility_filter;
2. если мало/0 — точная категория без compatibility;
3. затем широкая автомобильная категория;
4. после этого PartSnap сам фильтрует нерелевантные товары по названию.

Для battery используется eBay.de category 179846 (Batterien fürs Auto).
Если eBay вернул 0 результатов, интерфейс показывает, сколько результатов было на каждом этапе каскада.

Цель: не получать дворники по запросу Bosch S4, но и не обнулять выдачу слишком жёстким compatibility-фильтром.
