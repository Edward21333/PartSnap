# PartSnap MVP v0.20.1

Hotfix выбора автомобиля из каталога.

Причина:
в v0.20 интерфейс radio/select был добавлен, но JavaScript обработчики выбора каталога не попали в итоговый index.html.

Исправлено:
- radio `Выбрать из каталога` открывает select-блок;
- каталог загружается через `/api/vehicles`;
- каскад работает: марка → модель → год → двигатель;
- `Автомобиль неизвестен` снова скрывает каталог;
- успешный VIN decode переводит состояние в `подтверждён по VIN`;
- исправлен footer версии.
