# PartSnap MVP v0.15

Выдача eBay теперь разделена на три группы:

1. Подходящие по типу
2. Похожие детали
3. Остальные результаты eBay

Остальные результаты по умолчанию свёрнуты, но пользователь может раскрыть их.
Это сохраняет ширину поиска и одновременно не смешивает слабые результаты с основными.

`Лучшая цена подходящей детали` считается только по exact/likely.
В заголовке также показываются счётчики групп.
