# PartSnap MVP v0.12.3

UI/logic hotfix.

Проблема:
для деталей, где у PartSnap ещё нет собственного spec-comparator (например, рулевой шлейф),
карточка могла показывать красное `Совпадение характеристик 0%`.
Это выглядело как доказанная несовместимость, хотя характеристики вообще не сравнивались.

Исправлено:
- fit-score показывается только если реально есть сопоставимые характеристики;
- для обычных деталей без такого сравнения красный 0% исчезает;
- для аккумуляторов Voltage/Ah/CCA рейтинг остаётся;
- eBay compatibility badge остаётся отдельным сигналом, если eBay его вернул.

Принцип:
`0%` показываем только когда реально сравнили данные и получили плохой результат.
Если сравнения не было — не показываем процент вообще.
