# PartSnap MVP v0.17
Исправлена классификация ШРУСов в eBay.
Распознаются EN/DE варианты CV joint, Rzeppa, Gelenksatz, Gleichlaufgelenk, Antriebswellengelenk и др.
Пыльники, смазка, хомуты и ремкомплектные аксессуары отделяются.
Если заголовок явно продаёт сам CV joint вместе с boot/grease/clamps, это остаётся самой деталью.
Автомобиль без подтверждения — только подсказка.
